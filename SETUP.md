# 🎉 Birthday Website Setup Guide 🎂

## Quick Start (3 Simple Steps!)

### 1. Install Flask
```bash
pip install flask
```
*OR if you get permission errors:*
```bash
pip install --user flask
```

### 2. Run the Website
```bash
python app.py
```

### 3. Open in Browser
```
http://localhost:5000
```

## 🎊 That's it! Your birthday website is ready! 🎊

## 🎵 Adding Birthday Music

1. Find your favorite birthday songs (MP3, WAV, or OGG format)
2. Copy them to the `static/music/` folder
3. Refresh the website - they'll appear in the music player automatically!

**Suggested songs:**
- Happy Birthday (traditional)
- Birthday by The Beatles
- Celebration by Kool & The Gang
- Any of Laraib's favorite songs! 💕

## 📸 Adding More Photos

1. Copy your beautiful photos to the `static/music/` folder
2. Supported formats: JPG, PNG, GIF, WebP
3. Refresh the website - they'll appear in the gallery with hover effects!
