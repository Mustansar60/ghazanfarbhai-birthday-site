# 🎉 Happy Birthday Laraib Zahra! 🎂❤️

A beautiful, interactive birthday celebration website built with love from Ghazanfar Maqsood and your precious children: Hurain, Nalain, and Adan.

## ✨ Features

- **Animated Birthday Banner** with floating hearts and sparkle effects
- **Family Wishes Section** with heartfelt messages from your loved ones
- **Interactive Visitor Wishes** - friends and family can add their own birthday wishes
- **Photo Gallery** - displays all images from `static/images/` in a beautiful responsive grid
- **Birthday Music Player** - plays mp3 files from `static/music/` with full controls
- **Celebration Effects** - confetti, fireworks, and special cake wish animations
- **Responsive Design** - works perfectly on mobile and desktop
- **Beautiful Pink/Purple/Gold Theme** with glowing effects and animations

## 🚀 Quick Start

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Add your content:**
   - Place your favorite photos in `static/images/` (supports JPG, PNG, GIF, WebP)
   - Add birthday songs to `static/music/` (supports MP3, WAV, OGG)

3. **Run the website:**
   ```bash
   python app.py
   ```

4. **Open in browser:**
   ```
   http://localhost:5000
   ```

## 🎵 Adding Music

Simply drop your favorite birthday songs (MP3, WAV, or OGG format) into the `static/music/` folder. The music player will automatically detect them and make them available for playback.

## 📸 Adding Photos

Place your beautiful memories (JPG, PNG, GIF, or WebP format) in the `static/images/` folder. They will automatically appear in the photo gallery with click-to-enlarge functionality.
